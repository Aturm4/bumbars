# Bumbars

Интерактивный прототип многопользовательского симулятора жизни с ИИ-ведущим. Интерфейс выполнен на русском языке и включает ключевые экраны: Главная, Мир, Хост, План, Ритуалы, Профиль, Финансы и Компания.

## Запуск

Установить зависимости: npm install
Запустить разработку: npm run dev
Проверить сборку: npm run build
Проверить код: npm run lint

## Что уже работает

- навигация между пятью основными разделами;
- живой таймер текущего действия;
- временная шкала дня и недельный режим;
- управление ритуалами;
- диалог с Хостом и демонстрация предложения действия;
- интерактивная карта мира;
- профиль, финансы и компания;
- адаптивный мобильный интерфейс;
- уведомления и модальные окна.

Это законченный продуктовый срез frontend. Реальные игровые изменения пока имитируются локальным состоянием; серверная архитектура и следующие фазы описаны в ARCHITECTURE.md и docs/exec-plans/MASTER_PLAN.md.
