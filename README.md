# Bumbars

Bumbars — русскоязычный persistent life-sim для небольшой компании друзей. Игрок задаёт намерение, Хост готовит предложение, а deterministic backend рассчитывает цену, время, вероятность, вместимость персонажа и последствия.

## Запуск

Установить зависимости: npm install
Запустить разработку: npm run dev
Проверить сборку: npm run build
Проверить код: npm run lint
Проверить типы: npm run typecheck

## Что уже работает

- навигация между пятью основными разделами;
- живой таймер текущего действия;
- временная шкала дня и недельный режим;
- управление ритуалами;
- диалог с Хостом и серверные предложения с отдельным подтверждением;
- интерактивная карта мира;
- профиль, финансы и компания;
- адаптивный мобильный интерфейс;
- уведомления и модальные окна.

Клиент читает каноническое состояние из D1 через API. Реализованы persistent действия, capacity, deterministic RNG, двойные проводки, мир, профиль, организации, навыки, опыт и PWA shell. Production-gap между вертикальным срезом и целевой PostgreSQL/worker/Telegram-системой зафиксирован в docs/capability-gaps.md.
