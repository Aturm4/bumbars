## 22 августа 2026 — серверный вертикальный срез

Frontend simulation state удалён из пользовательского потока. Добавлен постоянный D1 adapter, серверные API-команды и оригинальный интерфейс поверх реального состояния.

- работают ActionProposal, отдельное подтверждение, отмена, running и resolved;
- стоимость, энергия, таймер и эффекты рассчитываются на сервере;
- повторное подтверждение идемпотентно и не повторяет списание;
- кошелёк меняется только через ledger-записи;
- просроченные действия безопасно завершаются при ближайшем обращении к API;
- ритуалы создаются, ставятся на паузу, возобновляются, пропускаются и отменяются с сохранением;
- интерфейс полностью русскоязычный и больше не копирует композицию референсов;
- каждая видимая кнопка выполняет действие или навигацию.

## Проверки серверного среза

- production build: успешно;
- lint: успешно;
- двойное подтверждение: баланс и энергия меняются один раз;
- отклонение предложения: баланс не меняется;
- lifecycle ритуала: create → pause → resume → skip → cancel;
- persistent restart: баланс, ledger, события и завершённые действия сохраняются.
