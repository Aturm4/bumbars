# Карта проекта

Bumbars — русскоязычный persistent life-sim для друзей с ИИ-ведущим.

## Источники истины

- продукт и ограничения: docs/product/requirements.md;
- архитектура: ARCHITECTURE.md и docs/architecture/system-overview.md;
- план и состояние: docs/exec-plans/MASTER_PLAN.md и progress.md;
- решения: docs/decisions/decision-log.md.

## Команды

- npm run dev — разработка;
- npm run build — production-сборка;
- npm run lint — статический анализ.

## Критические инварианты

1. ИИ не является базой данных или игровым движком.
2. Деньги, вероятности, таймеры, права и эффекты рассчитывает deterministic backend.
3. Любая опасная или платная команда сначала становится предложением и требует подтверждения.
4. Игрок и персонаж разделены: занятость персонажа не блокирует интерфейс.
5. Нет глобального уровня; компетентность выводится из опыта и доказательств.
6. Пользовательский интерфейс и продуктовая документация — на русском языке.
7. После значимого изменения обновлять progress.md и журнал решений.
